# Jeany Rose A. Calibuyot — Personal Portfolio

A responsive personal portfolio website created for the Web Systems and Technologies 1 final project.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git and GitHub (for version control and deployment)

## Features
- Home / introduction
- About me
- Skills
- Three project cards
- Education
- Contact information
- Responsive navigation for mobile
- Light/dark theme switcher
- Active navigation state

## Project files
- `index.html` — website structure and content
- `style.css` — layout, colors, and responsive design
- `script.js` — navigation and theme interactions
- `assets/profile.jpg` — add your own profile photo here

## Run locally
1. Download or clone this repository.
2. Add your photo as `assets/profile.jpg`.
3. Open `index.html` in a browser, or use Live Server in Visual Studio Code.

## Deploy with GitHub Pages
1. Create a public GitHub repository (for example, `jeany-rose-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Copy the public URL shown in the Pages settings.
7. Update this README with your actual live URL.
